# Prospecção Sites

Repositório único para apresentações comerciais de sites.

## Estrutura

Cada lead recebe uma pasta própria:

- `/beauty-care/`
- `/rei-do-oleo/`
- `/nome-do-cliente/`

Quando o GitHub Pages estiver ativo, cada pasta vira uma demonstração navegável no formato:

`https://douglasnegociosdigitais-tech.github.io/prospeccao-sites/nome-do-cliente/`

## Padrão das demos

- mobile-first
- HTML/CSS/JS estático
- rápido e leve
- CTA de contato
- avaliações e prova social quando houver dados reais
- localização e horários
- sem indexação em mecanismos de busca (`noindex`)
- sem dados inventados

O arquivo da raiz funciona apenas como painel interno de apresentações.
